#  PhishLens

PhishLens is an Android cybersecurity application designed to help users identify potential phishing attempts through suspicious URLs, QR codes, and messages.

The application is currently being developed for the 2027 M.A.D. Contest at Illinois State University.

##  Development Status

PhishLens is currently in active development.

Current Version: `v0.1.0`

## 🛡 Planned Features

- [ ] URL phishing scanner
- [ ] QR code scanner
- [ ] Suspicious message analysis
- [ ] Phishing risk assessment
- [ ] Detailed explanation of detected threats
- [ ] Scan history
- [ ] User-friendly cybersecurity recommendations

##  Project Goal

The goal of PhishLens is to make phishing detection easier to understand for everyday users. Instead of only warning users that something may be dangerous, PhishLens will explain the indicators that contributed to the risk assessment.
